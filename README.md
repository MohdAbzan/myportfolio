# Mohammed Abzan — Portfolio

Personal portfolio for Mohammed Abzan, MBA Business Analytics student and aviation operations professional.

## SEO / Google setup
- `robots.txt` allows search crawlers and points to the sitemap.
- `sitemap.xml` lists the canonical homepage.
- `site.webmanifest` provides installable/mobile branding.
- Multiple favicon sizes are included for browsers and search engines.
- Canonical, Open Graph, Twitter and Person structured-data metadata are included in `index.html`.

## Publish
Upload the complete contents of this folder to `mohdabzan.com`. Then add `https://mohdabzan.com/` in Google Search Console and submit `https://mohdabzan.com/sitemap.xml`.
